Ahora sí, los pasos que te tocan a ti (yo no puedo entrar a tus cuentas):

1. GitHub (en Replit):

Abre el panel de Git (botón aquí abajo)
Conecta tu cuenta de GitHub si te lo pide
Crea el repositorio con "Create repository on GitHub"
Cuando esté, me dices "ya está el repo" y yo subo todo el código
2. Railway (en railway.app):

New Project → Deploy from GitHub repo → eliges el repositorio que creaste
Agrega una base de datos: + New → Database → PostgreSQL
En el servicio de la app: Variables → agrega DATABASE_URL con referencia a la de Postgres (Railway te la sugiere: ${{Postgres.DATABASE_URL}})
En Settings → Generate Domain → esa será tu URL principal
Con eso, cada vez que yo suba código a GitHub, Railway se actualiza solo — eso es la actualización automática que querías.

Avísame cuando el repositorio de GitHub esté creado y conectado, y yo subo el código de una vez.
