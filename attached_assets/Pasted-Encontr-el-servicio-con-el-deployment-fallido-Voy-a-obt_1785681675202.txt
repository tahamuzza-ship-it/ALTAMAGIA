El problema está en tu repo. Necesitas sincronizar tu pnpm-lock.yaml con tu pnpm-workspace.yaml o package.json. Tienes dos opciones:

Opción rápida: Regenera el lockfile localmente

cd tu-repo
pnpm install --no-frozen-lockfile
git add pnpm-lock.yaml
git commit -m "Update pnpm lockfile"
git push

Opción en Railway: Desactiva la flag --frozen-lockfile en tu build si prefieres instalar directamente.
